# 测试

Agent 写测试有固定的倾向：每修一个问题就新开一个测试，同一件事在多个层级、多个调用点重复测，连文案、常量、类型已经保证的内容都要测一遍。单看每个测试都合理，累积起来，测试套件就变慢、变脆、失去信号。T3 Code 的 25,928 个测试中，有 43% 被判定为没有信号；删掉之后，测试总耗时下降 59%。但在没有护栏的三周里，测试数又涨回了 41%。

本参考给出日常写测试和审阅测试的规则，以及防止回涨的护栏。需要一次性清理存量时，见 [冗余测试清理](test-cleanup.md)。

## 写什么

- **测会坏的行为**：编排与状态流转、协议和格式转换、鉴权与权限边界、持久化与迁移、外部格式解析、确定性的竞态修复、本次修复改动的逻辑、项目文档和契约中写明必须成立的不变量。
- **不测这些**：类型已保证、琐碎逻辑、文案、冒烟、mock 镜像、框架基础行为（回调接线、props 原样渲染）、挂钟性能断言；以及下面三条规则排除的重复的表格行、多层重复、依赖时间的时序。各类别的判定细则见 [冗余测试清理](test-cleanup.md#2-评分标准)。
- **先扩展，再新增**：已有用例或用例表能覆盖时，在那里加一行数据或一条断言；表格驱动用 `it.each`、`pytest.mark.parametrize` 之类的写法。没有合适的用例时，才新写一个测试。不要在循环里声明测试。
- **只在一层测**：选在主分支上会失败的最低那一层。不在包装层、每个调用点、多端的同一份逻辑里重复测同一个场景。删除高层用例前，先确认低层覆盖了同一故障路径。
- **昂贵的测试只给离不开它的行为**：浏览器测试只用于布局与滚动、焦点和指针输入、真实 worker、组件与 hooks 的接线；端到端测试和需要容器、网络的集成测试，也只用于必须经过那条边界的行为。组件调用的逻辑，在旁边写单元测试。一个浏览器测试文件在 CI 里光加载模块就要花几秒，而一个单元测试只要几毫秒。
- **证据随缺陷类型而定**：逻辑、数据、状态、协议类缺陷，先写一个在主分支上失败的测试，尽量放进已有用例，再修复。纯视觉问题用修改前后的截图作证据，不加 UI 测试。没有可见表现的服务端修复，提交测试，并附一段运行记录。
- **确认测试真的能变红**：修复缺陷时，用旧实现或一次可撤销的定向故障注入，确认新测试会失败。如果它只是因为导入报错而失败，不算证据。

## 确定性

- 等待完成信号：事件、队列、`Deferred`、可观察的状态。不用固定时长的 `sleep`；确实没有信号可等时，轮询必须同时有判断条件和截止时间。
- 涉及时间的逻辑（过期、轮换、冷却）用确定性时钟推进，不依赖真实时间流逝。
- 不在单个测试上加超时参数，不重试；以项目统一的超时为上限。偶发失败要修好，不靠重试掩盖。
- 不用挂钟时间差做断言，改为断言事件和计数。
- 暂时跳过的测试，必须在上一行写明追踪编号和原因（例如 `// quarantine: #1234 <原因>`）。
- 这些都能机械识别，交给 lint 拦截，见 [经验回流](feedback-loop.md#机械规则写成检查)。

## 审阅测试

- 只有当缺少的测试能抓住真实回归时，才要求补测试。不要求每个常量、标签、`switch` 分支都有一条断言。
- 新测试违反上面的规则时，指出问题并给出一种具体修法：并入已有用例或表格、删除、只保留一层、把不需要渲染的浏览器测试改成单元测试。
- 评审机器人只审本次新增或扩大的测试；移动、重命名、删除的测试不算问题。它只要求更少或更小的测试，从不要求更多覆盖；没有问题时只输出一个固定短语。
- 评审提示词指向项目的测试文档，不要在提示词里另写一份清单。T3 Code 用评测对比过：88 个词、只写指针的提示词，和带内联清单的长版本效果相同；而内联清单让便宜的模型更容易误伤好测试。

## 防止回涨

- 测试规则只写在测试文档里，作者和评审都读它。指令文件只留一行指针，写明哪些任务要先读它，例如写测试、证明缺陷已修复、等待异步操作。
- 在 PR/MR 中统计本次新增和删除的测试声明数，按单元、浏览器、端到端等类型分开计。净增超过阈值（T3 Code 设为 +20），或新增了浏览器测试文件时，自动评论提醒；降回阈值以下就删除评论。统计声明数而不是耗时，因为 CI 耗时随负载波动很大：同一个文件单独跑 44 秒，资源争用时要 160 秒。
- 用评测守护测试评审规则。坏例子：文案逐处测试、包装层重复、表格行另起一个测试、mock 镜像、类型已保证、逻辑放进浏览器测试。好例子：死锁或竞态修复、重试修复、删除测试、正确地给表格加一行。修改评审规则时跑一遍。
- 测试数增长明显快于功能，或者 CI 变慢、偶发失败变多时，按 [冗余测试清理](test-cleanup.md) 做一次体检。
